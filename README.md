# BizFlow – Business Management & WhatsApp Billing System

BizFlow is a business management web application designed to manage customers, create bills, and send bill notifications through WhatsApp.

## 🚀 Live Project

https://biz-flow-pied-delta.vercel.app

## ✨ Features

- 🔐 Admin Login & Authentication
- 👥 Customer Management
- 🧾 Billing Management
- 💰 Automatic Grand Total Calculation
- 📱 WhatsApp Bill Notification
- 🗄️ MongoDB Database Integration
- 🔒 JWT-based Authentication
- 🌐 REST API Integration

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

### API & Tools
- Meta WhatsApp Cloud API
- Bruno API Client
- Git & GitHub
- Vercel
